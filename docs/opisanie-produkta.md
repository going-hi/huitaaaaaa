# MindBase — описание программного продукта

## 1. Общие сведения

**MindBase** — веб-платформа корпоративной базы знаний (Corporate Wiki / Knowledge Management System), предназначенная для создания, структурирования, поиска и совместного использования информации внутри команд и организаций.

Продукт решает задачу централизованного хранения документации, регламентов, инструкций, runbook'ов, обучающих материалов и лучших практик. В отличие от универсальных заметочников, MindBase ориентирован на **структурированную wiki-модель**: иерархия разделов, ролевая модель, группы доступа, файловый реестр и модуль обучения в едином интерфейсе.

Разработчик продукта — **ООО «Инним»**. Платформа распространяется как бесплатное решение без тарифных ограничений на количество участников и материалов.

---

## 2. Назначение и целевая аудитория

**Назначение:** автоматизация процессов управления знаниями (Knowledge Management) в малых и средних командах: IT-разработка, поддержка, HR, продажи, маркетинг, информационная безопасность.

**Целевая аудитория:**

- команды разработки (API-документация, архитектурные решения, онбординг);
- службы поддержки (шаблоны ответов, runbook'и);
- HR и обучение (курсы, чек-листы, аттестации);
- руководители и администраторы (регламенты, политики, контроль доступа);
- отдельные специалисты (личная база знаний с возможностью масштабирования до командной).

---

## 3. Архитектура и технологический стек

| Компонент | Технология |
|-----------|------------|
| Серверная часть | PHP 8+ (модульная структура `lib/`) |
| СУБД | MySQL 8.0 (InnoDB, FULLTEXT-поиск) |
| Клиентская часть | HTML, CSS, JavaScript (адаптивный интерфейс) |
| Формат контента | Markdown (статьи), бинарные файлы (документы) |

Архитектура построена по классической **трёхзвенной модели**: браузер → веб-сервер → реляционная база данных. Бизнес-логика вынесена в библиотеки (`lib/auth.php`, `lib/knowledge.php`, `lib/roles.php`, `lib/workspace.php` и др.), страницы выполняют роль контроллеров представления.

---

## 4. Мультитенантность: рабочие пространства (workspaces)

Ключевая особенность продукта — **изоляция данных по базам знаний**:

- у каждой команды или проекта — **отдельное рабочее пространство** (workspace);
- при регистрации пользователь автоматически получает **собственную пустую базу** и становится её владельцем;
- один пользователь может состоять в **нескольких базах** и переключаться между ними;
- весь контент (разделы, статьи, теги, документы, курсы, группы доступа) привязан к workspace;
- пользователь **не видит** базы, в которые его не добавили.

**Управление участниками:**

- администратор базы добавляет коллегу **по email** (аккаунт должен быть зарегистрирован в системе);
- администратор может **удалить участника** из базы (с очисткой его групп доступа в этом workspace);
- владельца базы удалить нельзя.

---

## 5. Регистрация, аутентификация и профиль

- **Регистрация** с указанием имени, email, пароля и названия первой базы знаний;
- **Вход и выход** с поддержкой безопасного редиректа после авторизации;
- **Профиль пользователя** — редактирование имени и должности;
- пароли хранятся в виде **хешей** (`password_hash`);
- защита форм от CSRF-атак (токены в сессии);
- сессионная модель доступа к закрытым разделам кабинета.

---

## 6. Ролевая модель и права доступа

Права определяются **внутри каждой базы знаний**, а не глобально:

| Роль | Возможности |
|------|-------------|
| **Владелец (owner)** | Полный контроль над базой, нельзя удалить или понизить |
| **Администратор** | Управление участниками, ролями, группами доступа, настройками |
| **Редактор** | Создание и редактирование статей, разделов, документов, курсов |
| **Пользователь** | Чтение доступных материалов, скачивание файлов, прохождение курсов |

**Группы доступа** — дополнительный уровень гранулярности:

- администратор создаёт группы (например: «Разработчики», «Поддержка», «HR»);
- группы назначаются **разделам каталога** и **документам**;
- пользователям назначаются одна или несколько групп;
- ограничения **наследуются** от родительского раздела к дочерним;
- недоступные ветки дерева разделов **скрываются** из навигации;
- администратор видит весь контент базы независимо от групп.

## 7. Каталог знаний

### 7.1. Иерархия разделов

- древовидная структура категорий с неограниченной вложенностью;
- у каждого раздела: название, slug, иконка, описание, порядок сортировки;
- создание, редактирование и удаление разделов (редакторами и администраторами);
- привязка групп доступа к разделу.

### 7.2. Статьи

- создание и редактирование статей в формате **Markdown**;
- поля: заголовок, краткое описание (excerpt), тело, привязка к разделу;
- автоматическая генерация URL-slug;
- учёт автора и даты обновления;
- **счётчик просмотров** и журнал просмотров по пользователям;
- специальный тип **справочных статей** для встроенной помощи;
- **теги** для дополнительной классификации.

### 7.3. Отображение

- страница раздела со списком статей и подразделов;
- страница статьи с рендерингом Markdown в HTML;
- хлебные крошки для навигации по дереву;
- адаптивный интерфейс личного кабинета.

---

## 8. Поиск

- **полнотекстовый поиск** по заголовку, описанию и телу статей (MySQL FULLTEXT);
- фильтрация по разделу;
- подсветка найденных фрагментов в результатах;
- поиск учитывает **права доступа** — пользователь видит только разрешённые статьи;
- глобальная строка поиска в шапке кабинета.

---

## 9. Модуль документов

Файловый реестр для хранения вложений вне wiki-статей:

- загрузка файлов форматов: PDF, DOC, DOCX, TXT, XLSX, CSV, MD (до 15 МБ);
- метаданные: название, тип, ответственный, папка (folder path);
- **группы доступа** к отдельным документам;
- скачивание через защищённый endpoint с проверкой прав;
- хранение файлов в каталоге `storage/documents/` на сервере.

---

## 10. Модуль обучения

Система курсов для онбординга и внутреннего обучения:

- **курсы** с типами: видео, документ, смешанный, тест/квиз;
- **уроки** внутри курса с привязкой к статьям базы знаний;
- учёт **прогресса пользователя** по курсу (процент завершения);
- отметка пройденных уроков;
- редактирование курсов и уроков (редакторами);
- сводная статистика по обучению на дашборде.

---

## 11. Личный кабинет и аналитика

**Дашборд** отображает:

- количество статей, разделов, участников команды;
- просмотры за последние 7 дней;
- **ленту активности** — недавно обновлённые статьи;
- быстрые ссылки на каталог, обучение, документы, создание статьи, настройки.

**Страница «Мои базы»** — список доступных workspace с ролями, переключение между базами, создание новых.

**Настройки базы:**

- переименование рабочего пространства;
- добавление участников по email;
- **экспорт** контента в Markdown или HTML.

---

## 12. Экспорт данных

- выгрузка всех доступных пользователю статей в **Markdown** (`.md`);
- выгрузка в **HTML** с конвертацией Markdown;
- экспорт учитывает права доступа к разделам;
- позволяет переносить знания в другие системы или архивировать.

---

## 13. Администрирование

| Раздел | Функции |
|--------|---------|
| **Пользователи** | Список участников текущей базы, назначение ролей, групп доступа, удаление из базы |
| **Группы доступа** | Создание, редактирование и удаление групп, привязка к разделам и документам |
| **Настройки** | Название базы, участники, экспорт |

---

## 14. Публичная часть и SEO

- **лендинг** с описанием возможностей, целевой аудитории, FAQ;
- SEO-оптимизация: meta-теги, Open Graph, JSON-LD (Schema.org);
- `robots.txt`, `sitemap.xml`;
- favicon, OG-изображение, адаптивная вёрстка;
- страницы входа и регистрации с SEO-метаданными.

---

## 15. Безопасность

- хеширование паролей (bcrypt через `PASSWORD_DEFAULT`);
- CSRF-защита всех форм изменения данных;
- whitelist разрешённых URL для редиректа после входа;
- проверка прав на каждом уровне: роль → группа → workspace;
- изоляция данных между базами знаний;
- валидация загрузки файлов (тип, размер);
- параметризованные SQL-запросы (prepared statements).

---

## 16. Краткая формулировка для аннотации диплома

> **MindBase** — программный комплекс управления корпоративными знаниями, реализующий мультитенантную модель баз знаний, иерархический каталог статей с поддержкой Markdown, полнотекстовый поиск, гибкую систему ролей и групп доступа, файловый реестр документов, модуль дистанционного обучения с отслеживанием прогресса, экспорт данных и веб-интерфейс личного кабинета. Система разработана на PHP и MySQL и предназначена для командной работы с документацией и внутренними регламентами организации.
